The CPF Model

What is CPF?

CPF stands for Cost Per Friend — a conversion model where the action is a user adding friend using Line App. Built on trust and social proof, it converts differently from standard CPA or CPL offers.

We invented it and We bridged the gap between advertisers running CPF campaigns and performance marketers who had never seen this model before, opening up a flow that most networks simply don't have.

The result? Significantly better EPC and ROI for affiliates who runing it.
